How it works

Events in. Fixes out.

Webhooks, tags, schedules and comment commands become jobs. The engine applies merge request policies, queues within each credential's limits, checks out the repository with its own toolchain and hands analyzers the tools they need. Results land where your team already looks.

What it does

One engine. Every chore of a fleet.

Analyzers share one report format, one queue and one way to propose changes — so a review comment, a lockfile fix and a release summary all reach people the same way.

MR policies

Rules before robots

Approve, merge, label or skip analyses on merge request events — per scope, idempotent per commit.

{
  "id": "release-auto-approve",
  "when": {
    "sourceBranch": "release/*",
    "targetBranch": "main",
    "author": { "bot": true }
  },
  "actions": [{
    "type": "approve",
    "requirePipeline": "success"
  }],
  "skipAnalyzers": "*",
  "stop": true
}

Everything is a contract.
