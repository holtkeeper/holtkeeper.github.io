Keyboard shortcuts

The panel works without a mouse: ⌘K finds anything, J and K step through records, and decisions have single keys. Single-letter keys work only outside text fields, so typing in a search box never approves anything. On Windows and Linux, read Ctrl for ⌘.

Everywhere

Section titled “Everywhere”
Keys Does
⌘K or Ctrl K Opens or closes the command palette, on every page, even inside a text field.
/ Focuses the page’s search or filter field (lists, Ops › Runs, Ops › Tasks, Settings search).
Esc Closes dialogs, the side sheet and the palette.

A skip link at the start of every page jumps to the content.

Command palette

Section titled “Command palette”
Keys Does
↑ ↓ Move the selection; it wraps around.
↵ Opens the selected result.
⌘-click Opens a page result in a new tab.
Esc Closes the palette.

A query starting with > searches actions, # repositories and @ people. See Command palette.

Lists and side sheets

Section titled “Lists and side sheets”
Keys Does
J Next row. With no sheet open, opens the first row.
K Previous row. With no sheet open, opens the last row.
↵ Opens the focused row in the side sheet.
Esc Closes the side sheet.

The sheet’s header shows where you are (“3 of 41”), and the open row lives in the URL, so a copied link opens the same record.

Inbox

Section titled “Inbox”

With an item open in the side sheet:

Keys Does
A Approves the open item.
R Rejects it.
S Snoozes it.

Approving and rejecting a task group still ask for confirmation. See Inbox.

Knowledge › Learnings

Section titled “Knowledge › Learnings”
Keys Does
J K Move the focused row.
X Toggles the focused row’s selection.
P Accepts the selected rows, or else the focused one, into its chosen scope.
D Rejects them.

The table’s footer shows these keys. See Learnings.

Chat composer

Section titled “Chat composer”
Keys Does
↵ Sends the message.
Shift ↵ Starts a new line.
@ Mentions someone who can see the thread, Holtkeeper first.
/ at the start Switches to command mode with matching commands.
Arrows, Tab Pick a mention or command from the list.
Esc Closes the list.
