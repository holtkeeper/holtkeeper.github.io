Start

What is Holtkeeper

Holtkeeper is a self-hosted keeper for a fleet of repositories. It reviews merge requests, ships dependency upgrades that fix their own breaking changes, audits security and licenses, and runs releases — across monorepos and polyrepos, npm and Go, from a homelab with five repositories to a production fleet with hundreds.

People work in the panel. Coding agents read the same data over MCP before they change code.

What it does

Section titled “What it does”
  • Reviews every merge request with an AI reviewer that posts findings on the line, with suggestions you apply in one click.
  • Indexes the fleet: which repository uses which library at which version, the public API of every package, runtimes, base images and licenses.
  • Upgrades dependencies in waves: an agent opens one merge request per repository, fixes what the upgrade breaks and waits for CI.
  • Audits advisories and licenses, and fixes them the same way.
  • Releases: knows what is ready, writes the changelog and announces the version with the repositories it would break.
  • Remembers: a team guide, notes and learnings that both people and agents read.
